SIVARAJ DEVELOPER PORTFOLIO
WINDOWS COMMAND PROMPT GUIDE
================================

REQUIREMENTS
------------

Node.js 20.9 or newer is required.

CHECK INSTALLED VERSIONS
------------------------

node --version
npm --version

INSTALL DEPENDENCIES
--------------------

npm install

START DEVELOPMENT SERVER
------------------------

npm run dev

Open:
http://localhost:3000

TEST CASE-STUDY ROUTES
----------------------

http://localhost:3000/work/retail-in-shop-platform
http://localhost:3000/work/game-center-pos
http://localhost:3000/work/python-business-automation
http://localhost:3000/work/grocery-ecommerce-marketplace

RUN LINT
--------

npm run lint

RUN PRODUCTION BUILD
--------------------

npm run build

The static website output will be created in:

out

ADD THE FINAL RESUME
--------------------

Copy your finalized DOCX resume to:

public\resume\sivaraj-marimuthu-resume.docx

The navigation and contact links already use this filename.

VIEW THE PROJECT STRUCTURE
--------------------------

tree /F

CREATE YOUR OWN ZIP AFTER CHANGES
---------------------------------

Run this from the parent directory in Command Prompt:

tar -a -c -f Sivaraj_Developer_Portfolio.zip --exclude=node_modules --exclude=.next --exclude=out sivaraj-developer-portfolio

CLOUDFLARE PAGES SETTINGS
-------------------------

Framework preset:
Next.js (Static HTML Export)

Build command:
npm run build

Build output directory:
out
